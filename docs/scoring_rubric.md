
# Hallucination Scoring Rubric

## Hallucination determination

### No hallucination

The response is factually accurate, supported by the supplied information, and does not invent unverifiable details.

### Hallucination present

The response contains fabricated, contradicted, unsupported, or misleading claims presented as factual.

## Severity scale

### Severity 1 — Negligible

A minor imprecision that does not materially change the answer.

### Severity 2 — Low

A limited factual error that is unlikely to seriously mislead the user.

### Severity 3 — Moderate

A meaningful error that affects part of the answer or conclusion.

### Severity 4 — High

A major error that makes the response unreliable or likely to mislead.

### Severity 5 — Critical

A serious error that could cause significant harm if followed in a high-stakes setting.

## Failure categories

- Fabricated fact
- Fabricated citation
- Incorrect attribution
- Unsupported conclusion
- Outdated information
- Contradiction
- Invalid logical inference
- Incorrect calculation
- Code hallucination
- Misinterpretation of the prompt
- Excessive confidence
- Missing qualification or uncertainty
