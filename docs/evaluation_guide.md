
# Evaluation Guide

Each model response should be evaluated using the following process.

## 1. Preserve the original response

Copy the response exactly as generated. Do not correct spelling, wording, citations, or calculations.

## 2. Identify factual claims

List the claims that can be independently verified.

## 3. Verify the claims

Use reliable primary or authoritative sources whenever possible.

## 4. Compare against the expected answer

Determine whether the model reached the correct answer and used valid reasoning.

## 5. Identify hallucinations

Record any fabricated, unsupported, contradicted, outdated, or misleading claims.

## 6. Classify the failure

Assign the most appropriate failure category from the scoring rubric.

## 7. Assign severity

Use the five-level severity scale.

## 8. Explain the judgment

Write a concise explanation identifying:

- what the model claimed;
- why the claim is incorrect or unsupported;
- what the correct information is;
- which evidence supports the correction.

## 9. Record uncertainty

When the evidence is unclear, do not force a definitive judgment. Mark the evaluation for additional review.
